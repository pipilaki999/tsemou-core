# TSEMOU Design System v2.2.0

This release introduces the reusable Company Layout Engine.

Includes:
- 3-column desktop layout: left rankings, center content, right intelligence sidebar.
- Wider hero with controlled height.
- KPI metric cards with icons.
- Logo-style brand marks for major companies and fallback initials.
- Responsive layout: 3 columns desktop, 2/1 column tablet/mobile.
- Reusable UI language: TSEMIT, TSEMScore, TSEMIDENCE, TSEMPORT.
- Side intelligence modules: Timeline, Related Entities, Why this TSEMScore, Positive Actions, Community Voice.
