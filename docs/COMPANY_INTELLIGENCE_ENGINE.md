# Company Intelligence Engine v1.0 Foundation / Plugin v1.3.2

Purpose:
- Build initial intelligence reports for companies.
- Create Candidate Evidence Queue.
- Support human review workflow.
- Does not publish Evidence.
- Does not modify Trust Score.

Admin:
TSEMOU OS -> Company Intelligence

Current:
- Select company
- Add research notes
- Add candidate evidence lines
- Store _tsemou_company_intelligence_report JSON
- Store candidate evidence count
- Logs and overview

Future:
- AI research
- Source sensors
- Evidence Discovery integration
- Human verification UI
