# TSEMOU Design System v1.0

Locked terms:
- TSEMIT: user participation action.
- TSEMScore: entity score.
- TSEMIDENCE: verified or reviewable evidence.
- TSEMPORT: full entity report/file.

Company UX release:
- Main shortcode remains [tsemou_company_directory]
- Company cards use TSEMPORT and TSEMIT.
- Evidence language replaced by TSEMIDENCE.
- Trust language replaced by TSEMScore.
- Premium dashboard layout with side rankings, colorful hero, timeline, related entities and participation CTA.
