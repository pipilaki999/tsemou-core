# TSEMOU Company Page v2 - Clean Renderer

Use only one shortcode in Elementor:

[tsemou_company_page]

Elementor template should contain:
- Header/menu
- One Shortcode widget with [tsemou_company_page]
- Footer

Do not keep old Elementor sections for:
- old Trust Score columns
- old Country / Industry columns
- old Summary blocks
- old Related / Timeline blocks
- old Evidence widgets

The plugin renders the official Company Page order:
1. Hero
2. Stats
3. Overview
4. Trust Engine
5. Community Vote
6. Summary / Concerns / Positive Notes
7. Evidence Feed
8. Related Articles
9. Timeline
